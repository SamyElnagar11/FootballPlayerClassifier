How it works

From pixels
to a name.

PLAYER·AI locates the face in your photo, breaks it down into features a classifier can compare, then scores it against every player it was trained on.

  1. 01
    Detect OpenCV locates the face and eyes in the frame.
  2. 02
    Transform A wavelet transform isolates the features that matter.
  3. 03
    Classify An SVM model scores the face against the trained roster.
  4. 04
    Return The best match comes back with a confidence score.
